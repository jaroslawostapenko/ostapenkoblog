Recenzja Google Chat w 2026: Jak Zbudować Potężne Boty i Automatyzacje Korporacyjne

Yaroslav Ostapenko
21 Kwietnia 2026
Czas czytania: 28 min

Cześć! Nazywam się Yaroslav Ostapenko i od lat zajmuję się wdrażaniem infrastruktury IT w dużych organizacjach. Kiedy mówimy o komunikacji w firmie, przez lata na ustach wszystkich pojawiał się Slack lub Microsoft Teams. Jednak Google metodycznie i po cichu rozwijało swoje narzędzie wewnątrz ekosystemu Workspace.

W 2026 roku Google Chat nie jest już tylko naiwną próbą zastąpienia starego Google Hangouts. Stał się on potężnym, programowalnym hubem, który integruje sztuczną inteligencję (Gemini) z Twoimi plikami na Dysku. Dzisiaj z punktu widzenia dewelopera przyjrzymy się, jak napisać pod tę platformę genialnego bota (przy użyciu Google Apps Script) oraz jak odbierać zdarzenia asynchroniczne za pomocą języka Python.

"Google Chat wygrał w mojej firmie nie dlatego, że miał najpiękniejsze gify czy emoji. Wygrał dlatego, że napisanie bota, który wyciąga raport finansowy z Google Sheets i publikuje go w pokoju zarządu w postaci interaktywnej Karty (Card V2), zajęło mi zaledwie 30 minut." – Yaroslav Ostapenko

1. Ewolucja - Od Hangouts do Spaces (Pokoi)

Użytkownicy pamiętający klasyczne, zielone okienko Hangouts mogą przeżyć szok. Google Chat w 2026 posiada bardzo rygorystyczny, przejrzysty podział. Lewy panel nawigacyjny dzieli się na:

  • Czaty Pokoje (Spaces): Przestrzenie przeznaczone do pracy nad konkretnymi projektami (np. #Wdrożenie-ERP-2026). Różnią się one zasadniczo od zwykłych czatów grupowych tym, że posiadają tzw. Wątki (Threaded replies). Dzięki temu rozmowa o błędzie w kodzie nie miesza się z ustaleniami o zamawianiu pizzy na piątek.
  • Wiadomości Prywatne (Direct Messages): Szybka, nieformalna komunikacja 1-on-1 z jednym pracownikiem lub małą, doraźną grupką bez tworzenia całego oficjalnego Pokoju.
  • Mentiony i Aplikacje (@Mentions & Apps): Skoncentrowany widok, gdzie widzisz wyłącznie miejsca, w których ktoś (lub bot!) oznaczył Cię do konkretnego działania.

2. Gemini AI w Google Chat

Żaden produkt Google w 2026 nie może uciec przed integracją z AI. W przypadku Google Chat, silnik LLM Gemini działa w sposób wybitnie kontekstowy, widząc historię Twoich wirtualnych Pokoi.

Podsumowanie Wątków

Wracasz po 2 tygodniach urlopu i widzisz, że pokój "#Projekt-X" ma 1400 nowych wiadomości? Nie musisz ich czytać. Klikasz przycisk "Summarize this Space", a Gemini AI w ciągu 5 sekund generuje krótki raport w punktach: Kto podjął kluczowe decyzje, jakie pliki udostępniono i jakie zadania zostały Ci przypisane, póki byłeś nieobecny.

3. Programowanie Botów (Google Apps Script)

Narzędzie staje się potężne dopiero wtedy, gdy możemy je zautomatyzować. Google Chat pozwala na stworzenie własnej aplikacji (Aplikacja typu Chat App / Bot), z którą użytkownicy mogą rozmawiać przez interfejs komunikatora, oznaczać znakiem @ i wydawać jej polecenia ułatwiające pracę w firmie.

Zbudujemy teraz pełnego Bota używając Google Apps Script (GAS). Kiedy zapytasz go "@MojaFirmaBot jaki jest status", bot odpyta wirtualną bazę i odpowie piękną, interaktywną Kartą.

Skrypt Serwera Bota (Code.gs)

/**
 * YAROSLAV OSTAPENKO - 2026
 * SKRYPT: Pełnoprawny Bot dla Google Chat z użyciem Apps Script (ES6)
 * Pamiętaj o włączeniu API Google Chat w konsoli Google Cloud (GCP)
 * i podaniu ID tego wdrożenia (Deployment ID) w zakładce "Configuration".
 */

/**
 * Zdarzenie wywoływane gdy bot zostanie DODANY do Pokoju (Space)
 * @param {Object} event Obiekt zdarzenia przysłany przez serwery Google
 * @return {Object} Odpowiedź, która zostanie wydrukowana w czacie na powitanie
 */
function onAddToSpace(event) {
  let message = "";
  if (event.space.type === "ROOM") {
    message = `Dziękuję za zaproszenie do pokoju ${event.space.displayName}! 
    Napisz "@Bot status", aby wygenerować raport.`;
  } else {
    message = `Cześć ${event.user.displayName}! Cieszę się, że napisałeś na priv.`;
  }
  return { "text": message };
}

/**
 * Zdarzenie wywoływane przy USUNIĘCIU bota z pokoju (Logowanie w celach audytu)
 */
function onRemoveFromSpace(event) {
  console.log(`Bot usunięty z pokoju: ${event.space.name} przez ${event.user.name}`);
}

/**
 * GŁÓWNA FUNKCJA: Wywoływana za każdym razem, gdy użytkownik napisze do bota
 * @param {Object} event 
 * @return {Object} Odpowiedź (Zwykły Tekst lub skomplikowany JSON Karta V2)
 */
function onMessage(event) {
  // Wyciągamy czysty tekst od użytkownika, usuwamy ewentualne spacje i Mention samego bota
  const userText = event.message.text.trim().toLowerCase();
  
  // Detekcja polecenia
  if (userText.includes("status")) {
    // Generujemy odpowiedź w formie interaktywnego Widgetu
    return createStatusCardV2Response(event.user.displayName);
  } else if (userText.includes("pomoc")) {
    return { "text": "Dostępne komendy: `status`, `pomoc`." };
  } else {
    // Fallback gdy bot nie rozumie pytania
    return { 
      "text": `Przepraszam ${event.user.displayName}, nie rozumiem komendy: "${userText}". 
      Spróbuj napisać "@Bot pomoc".` 
    };
  }
}

4. Architektura Interfejsu: Card V2 (JSON Payload)

Czysty tekst jest nudny i nie zachęca do klikania. Nowoczesne boty komunikują się za pomocą Card V2 (Karty Wersji 2). Jest to ustrukturyzowany ładunek JSON, który Google Chat potrafi zinterpretować, rysując na ekranie użytkownika kolumny, kolorowe przyciski, oddzielające je linie (Dividery) czy ikony.

Nasz bot z poprzedniego kroku, wywołując polecenie "status", używa poniższej funkcji do zbudowania ogromnego interfejsu wizualnego.

Jak inżynier łatwo zauważy, budowa JSONa w Google Chat nie jest płaska – przypomina drzewo HTML. Mamy głęboko zagnieżdżone sections, w nich widgets, a w nich dopiero buttonList czy textParagraph. Zapewnia to ogromną elastyczność przy renderowaniu UI na telefonach z Androidem, gdzie Google Chat sam dostosowuje wielkość okna do ekranu!

5. Webhooki Przychodzące: Integracja z Python (FastAPI)

A co jeśli nie chcesz pisać całego "bota", a potrzebujesz jedynie jednokierunkowej notyfikacji? Masz na serwerze skrypt, który po zakończeniu ciężkich obliczeń ma wysłać powiadomienie "Gotowe" na pokój całego zespołu deweloperskiego?

Wchodzimy w ustawienia Pokoju (Space) w Google Chat i klikamy opcję Apps & Integrations -> Webhooks. Generujemy tam specjalny adres URL zaczynający się od chat.googleapis.com/v1/spaces/....

Teraz użyjemy super-szybkiego Pythona, frameworka httpx oraz FastAPI by odpytać ów webhook z zewnętrznego VPSa.

# YAROSLAV OSTAPENKO - 2026 - PUSH DO GOOGLE CHAT WEBHOOK
import asyncio
import httpx
import sys

# URL uzyskany po wygenerowaniu Webhooka w interfejsie Google Chat Space
# TRZYMAJ GO W .ENV W ŚRODOWISKU PRODUKCYJNYM (To jak hasło do Twojego pokoju!)
WEBHOOK_URL = "https://chat.googleapis.com/v1/spaces/XXXXX/messages?key=YYYYY&token=ZZZZZ"

async def send_alert_to_chat(message: str, error_level: str = "INFO"):
    """
    Funkcja asynchroniczna powiadamiająca kanał IT na Google Chat
    wykorzystująca Incoming Webhook i prosty ładunek (Payload) z Card V2.
    """
    
    # Ustawiamy kolor komunikatu w zależności od krytyczności usterki
    color_hex = "#10b981" if error_level == "INFO" else "#ef4444"
    icon = "✅" if error_level == "INFO" else "🚨"

    # Budujemy ładunek zgodny z restrykcyjnym standardem Google
    payload = {
        "cardsV2":[
            {
                "cardId": "alert_bot_card",
                "card": {
                    "header": {
                        "title": f"Alert Systemowy [{error_level}]",
                        "subtitle": "Serwer Aplikacyjny Node-01"
                    },
                    "sections":[
                        {
                            "widgets":[
                                {
                                    "textParagraph": {
                                        "text": f"{icon} Wiadomość: {message}"
                                    }
                                }
                            ]
                        }
                    ]
                }
            }
        ]
    }

    # Asynchroniczne wysłanie POST przy użyciu HTTPX
    async with httpx.AsyncClient() as client:
        try:
            response = await client.post(
                WEBHOOK_URL, 
                json=payload,
                headers={"Content-Type": "application/json; charset=UTF-8"}
            )
            response.raise_for_status()
            print(f"Pomyślnie wysłano alert na Google Chat! Status: {response.status_code}")
        except httpx.HTTPStatusError as exc:
            print(f"Błąd HTTP podczas wysyłania do Google Chat: {exc.response.text}")
        except Exception as e:
            print(f"Nieprzewidziany błąd sieciowy Python: {e}")

# Uruchomienie skryptu (np. z Crontaba)
if __name__ == "__main__":
    test_msg = "Zadanie ETL zostało pomyślnie sfinalizowane. Baza uaktualniona o 3:00 AM."
    asyncio.run(send_alert_to_chat(test_msg, error_level="INFO"))

Powyższy skrypt nie musi być "akceptowany" przez administratorów Google Workspace jak ma to miejsce z pełnymi botami. Zwykły Webhook to genialny, partyzancki sposób inżynierów na integrację logów z GitHuba, GitLaba, Docker Swarm'a lub Kubernetes bezpośrednio na ekran Twojego smartfona z zainstalowaną apką Google Chat.

6. Starcie Gigantów: Google Chat vs Slack vs Microsoft Teams

Niezależnie od moich sympatii do środowiska Google, zachowajmy inżynierski obiektywizm. Zobaczmy, na co tak naprawdę decydujemy się w firmie w 2026 roku.

Cecha / Narzędzie Google Chat Slack (Salesforce) Microsoft Teams
Integracja Plików Natywna, perfekcyjna synchronizacja z Google Drive i uprawnieniami Docs. Oparta o zewnętrzne wtyczki, dobre udostępnianie, ale limitowane podglądy na żywo. Perfekcyjna, hermetyczna integracja z SharePoint i ekosystemem OneDrive/Word.
Koszt w 2026 r. Darmowy dla subskrybentów każdej wersji Google Workspace. Bardzo Wysoki (Bolesny abonament per-użytkownik za Enterprise). Darmowy wewnątrz planów biznesowych Office 365.
Budowa Botów API Wymaga nauki Card V2 JSON, doskonały hosting przez Google Apps Script wprost z przeglądarki. Niesamowicie potężny Block Kit Builder, wymaga własnego hostowania backendu (Node/Python). Skomplikowany cykl wdrożeniowy (Azure Bot Framework) z wysokim progiem wejścia.
Wątkowanie (Threading) Bardzo czyste (Wymuszane lub Opcjonalne w zależności od ustawień pokoju). Genialne, stało się rynkowym standardem UI/UX dla developerów na całym świecie. Chaotyczne. Czasem łatwo stworzyć nowy wątek zamiast odpisać w starym z powodu mylącego "pola tekstu".
Rozmowy Wideo / Audio Automatyczny przycisk generujący pokoje w niesamowicie lekkim Google Meet. Wbudowane Slack Huddles (dobre na szybkie pogaduchy audio w zespole). Dominator ciężkich, korporacyjnych webinarów na tysiące osób z potężnymi opcjami kontroli wideo.

8. Podsumowanie Wniosków

9. Najczęściej Zadawane Pytania (Wielkie FAQ 2026)

Czym różni się Google Chat od historycznego programu Google Hangouts?

Zarówno koncepcyjnie, architektonicznie, jak i rynkowo to dwa inne byty. Google Hangouts był w dużej mierze płaskim komunikatorem konsumenckim z listą kontaktów. Google Chat (zapoczątkowany jako Hangouts Chat) to profesjonalne, korporacyjne narzędzie zbudowane do walki w segmencie B2B. Opiera się na zamkniętych pokojach roboczych (Spaces), pozwala na restrykcyjne kontrolowanie wycieku danych przez panel Google Vault, udostępnia interfejs programistyczny API dla zewnętrznych serwerów i jest silnie powiązany z bezpieczeństwem domen korporacyjnych Google Workspace.

Jak zacząć pisać własnego bota (Aplikację Chat) bez płacenia za hosting serwera AWS?

Najszybszym, darmowym i w 100% bezserwerowym (Serverless) sposobem rekomendowanym przeze mnie jest użycie wewnętrznego ekosystemu Google Apps Script. Tworzysz nowy, pusty skrypt bezpośrednio na swoim Dysku Google. Zaznaczasz w konfiguracji "Włącz interfejs API Google Chat", piszesz funkcję parsującą onMessage(event) i publikujesz skrypt. Serwery Google same przejmują na siebie wybudzanie kodu, zarządzanie certyfikatami SSL i odbieranie JSONów, oszczędzając Ci dziesiątek godzin konfigurowania routerów i firewalli pod zewnętrzne boty Node.js.

Czy asystent AI (Google Gemini) potrafi sam stworzyć i wrzucić powiadomienie?

W 2026 roku sztuczna inteligencja Gemini działa na poziomie interfejsu (UX/UI) pomagając użytkownikom ludzkim - np. generując szybkie odpowiedzi na podstawie czytania kontekstu (Smart Reply) albo budując błyskawiczne konspekty z 500 nieprzeczytanych powiadomień po urlopie. Gemini samo z siebie nie tworzy autonomicznych "botów-agentów", które wysyłają wiadomości co 10 minut z prognozą pogody. Tego typu proaktywne operacje musisz zaprogramować samodzielnie, używając Webhooków i frameworków developerskich (Python / Node).

Zbudowałem kartę Card V2 w JSON, ale dostaję dziwny błąd w API podczas wysyłki. Gdzie szukać pomocy?

Format Card V2 w API Google Chata jest absolutnie rygorystyczny i nie wybacza literówek. Jedno niezamknięte zagnieżdżenie widgets w strukturze sections spowoduje twarde odrzucenie zapytania (HTTP 400 Bad Request). Najlepszym przyjacielem dewelopera jest w tym momencie oficjalne internetowe narzędzie "Card Builder Tool" oferowane przez Google. Pozwala ono w locie modyfikować JSON w przeglądarce i oglądać wygenerowany wygląd interfejsu na wizualnej makiecie telefonu przed ostatecznym zakodowaniem ładunku w Twoim skrypcie Python.
